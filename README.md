# Machine Learning Sales Prediction

## Project Overview
This project uses Machine Learning to predict sales values based on product, pricing, quantity, and territory-related features.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Machine Learning Workflow
- Data Loading
- Data Cleaning
- Feature Selection
- Train-Test Split
- Linear Regression Model
- Model Evaluation
- Data Visualization

## Features Used
- Quantity
- Unit Price
- Cost
- ProductKey
- SalesTerritoryKey

## Target Variable
- Sales

## Model Evaluation
- R² Score: 0.9795
- Mean Absolute Error: 119.17

## Key Insights
- The model achieved very high prediction accuracy.
- Unit Price and Cost strongly influence sales prediction.
- The regression model successfully captured sales patterns.
